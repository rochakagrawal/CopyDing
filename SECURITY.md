# Security Policy

## Supported versions

Security fixes are provided for the latest published version of CopyDing.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/rochakagrawal/CopyDing/security/advisories/new).
Do not disclose the vulnerability in a public issue before a fix is available.

Include the affected CopyDing and macOS versions, steps to reproduce, expected
impact, and any suggested mitigation. Use synthetic test content and remove
personal paths, account names, credentials, and clipboard contents from logs or
screenshots. Do not submit real confidential clipboard data.

Reports should receive an acknowledgement within seven days. Updates will be
provided as investigation progresses, and public disclosure will be
coordinated after a fix or mitigation is ready.

## Scope

Security issues include unintended clipboard disclosure, unsafe handling of
clipboard history, privilege-boundary problems, and unauthorized access to
copied data. General support requests and ordinary bugs can use GitHub Issues.
